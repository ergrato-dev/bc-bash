# Webgrafía — Semana 13

|---------|-------------|
| [man bash (man7.org)](https://man7.org/linux/man-pages/man1/bash.1.html) | El manual de bash: busca `JOB CONTROL`, `wait` (con `-n`), `Process Substitution`, `Coprocesses` y `SIGNALS` |
| [Greg's Wiki — ProcessManagement](https://mywiki.wooledge.org/ProcessManagement) | Cómo lanzar, esperar y parar procesos desde bash sin trucos frágiles: `$!`, `wait`, límites de trabajos y por qué no buscar pids con `ps \| grep` |
| [man xargs (man7.org)](https://man7.org/linux/man-pages/man1/xargs.1.html) | Todas las opciones de `xargs`: `-0`, `-P`, `-n`, `-I` y los códigos de salida (`123`, `124`, `125`...) |
| [man 5 crontab (man7.org)](https://man7.org/linux/man-pages/man5/crontab.5.html) | El formato de una línea de cron: los cinco campos, rangos, listas, `*/N`, el `%` y las variables que se pueden poner al principio |
| [systemd.timer (freedesktop.org)](https://www.freedesktop.org/software/systemd/man/latest/systemd.timer.html) | Referencia de los archivos `.timer`: `OnCalendar`, `Persistent`, `OnBootSec` y cómo se enlazan con su `.service` |
