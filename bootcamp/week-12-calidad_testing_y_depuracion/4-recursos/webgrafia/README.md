# Webgrafía — Semana 12

| Recurso | Descripción |
|---------|-------------|
| [Wiki de ShellCheck](https://www.shellcheck.net/wiki/) | Una página por aviso (`SC2086`, `SC2045`, `SC2155`...): qué detecta, por qué es un problema y cómo arreglarlo. La URL de cada aviso sale al final de la salida de `shellcheck` |
| [bats-core: Writing tests](https://bats-core.readthedocs.io/en/stable/writing-tests.html) | Referencia de `run` y sus opciones (`-N`, `--separate-stderr`), `load`, `skip`, `setup`/`teardown`, `setup_file` y la salida a `>&3` |
| [mvdan/sh (shfmt)](https://github.com/mvdan/sh) | El repositorio de shfmt: sus opciones (`-i`, `-ci`, `-sr`, `-d`, `-l`, `-w`) y las claves de `.editorconfig` que entiende |
| [man bash (man7.org)](https://man7.org/linux/man-pages/man1/bash.1.html) | El manual de bash: busca `PS4`, `BASH_XTRACEFD`, `BASH_SUBSHELL`, `LINENO`, `BASH_COMMAND`, `trap` (con `ERR`) y la palabra reservada `time` con `TIMEFORMAT` |
| [Bash Hackers Wiki — Debugging tips (archivo)](https://web.archive.org/web/2023/https://wiki.bash-hackers.org/scripting/debuggingtips) | Trucos para depurar: `PS4` con el número de línea y la función, trazas a un archivo, `bash -n` y mensajes de error que dicen dónde |
