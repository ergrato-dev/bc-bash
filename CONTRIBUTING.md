# Cómo contribuir

Este repositorio **no acepta pull requests externos** (se cierran automáticamente). Si encontraste un error o tienes una sugerencia, abre un **Issue** con la plantilla que corresponda:

- 🐛 [Error en un ejercicio o script](.github/ISSUE_TEMPLATE/bug_report.md)
- 📚 [Mejora de documentación](.github/ISSUE_TEMPLATE/documentation.md)
- 💡 [Propuesta](.github/ISSUE_TEMPLATE/feature_request.md)
- ❓ [Pregunta](.github/ISSUE_TEMPLATE/question.md)

Incluye siempre:

1. La semana y el archivo (`bootcamp/week-NN-.../2-practicas/lab-NN-.../README.md`).
2. El paso donde te quedaste y el comando exacto que ejecutaste.
3. El output completo, y el de `./scripts/verificar-semana.sh --doctor` dentro del laboratorio.

Las reglas de contenido del bootcamp (idioma, estructura, estilo de scripts y diagramas) están en [CLAUDE.md](CLAUDE.md).
